# 🏡 SpaceHeaven

SpaceHeaven is a full-stack web application where users can explore, create, update, and delete property listings. It is built using Node.js, Express.js, MongoDB Atlas, Mongoose, and EJS. This project helped me understand CRUD operations, routing, database integration, and deployment.

## Live Demo

https://space-heaven.vercel.app

## Features

- View all property listings
- Add a new listing
- Edit existing listings
- Delete listings
- View detailed information about each listing
- MongoDB Atlas integration
- Responsive interface using EJS templates

## Installation

Clone the repository

```bash
git clone https://github.com/Harshvardhan9560/SpaceHeaven.git
```

Move into the project folder

```bash
cd SpaceHeaven
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
ATLASDB_URL=your_mongodb_connection_string
```

Run the project

```bash
node app.js
```

Open your browser and visit

```
http://localhost:8080
```
